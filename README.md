## Overview
This individual project demonstrates PL/SQL GOTO statements, stored functions, exception handling, and the use of stored functions inside SQL queries. The examples use an employee/payroll scenario.

## How to Run
1. Run `00_setup/create_tables.sql`.
2. Run the functions in `02_functions/`.
3. Run the programs in `01_goto/`.
4. Run the tests in `03_tests/`.
5. Verify the results and screenshots.

## Tasks
- **A1:** Number/performance classifier using GOTO.
- **A2:** Salary review using GOTO.
- **A3:** Illegal GOTO demonstration and corrected version.
- **A4:** Salary review rewritten without GOTO.
- **B1:** Annual salary function.
- **B2:** Years-of-service function.
- **B3:** Tax calculator.
- **B4:** Department-name function with exception handling.
- **B5:** Functions used inside a SQL SELECT query.
- **C1:** Payroll validation function.
- **C2:** Reflection in `docs/REFLECTION.md`.
